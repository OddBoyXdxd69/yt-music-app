Implement a robust, error-free YouTube audio streaming and metadata engine powered entirely by YouTube's native InnerTube API with 0% bot-gating and zero signature cipher errors:

1. Search Endpoint:
- POST to https://www.youtube.com/youtubei/v1/search
- Payload:
  {
    "query": queryText,
    "context": {
      "client": {
        "clientName": "WEB",
        "clientVersion": "2.20240101.00.00",
        "hl": "en",
        "gl": "US"
      }
    }
  }
- Headers: User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36, Content-Type: application/json
- Parse: videoRenderer nodes to extract videoId, title, ownerText, lengthText, and thumbnails.

2. Zero-Cipher Audio Stream Extraction (Bypassing LOGIN_REQUIRED & Signature Ciphers):
- Do NOT use the WEB client for player stream extraction, as it triggers LOGIN_REQUIRED and signature-scrambled URLs.
- POST to https://www.youtube.com/youtubei/v1/player
- Payload:
  {
    "videoId": videoId,
    "context": {
      "client": {
        "clientName": "ANDROID_MUSIC",
        "clientVersion": "6.42.52",
        "androidSdkVersion": 34,
        "hl": "en",
        "gl": "US"
      }
    }
  }
- Headers:
  - User-Agent: com.google.android.apps.youtube.music/6.42.52 (Linux; U; Android 14) gzip
  - Content-Type: application/json
  - X-YouTube-Client-Name: 21
  - X-YouTube-Client-Version: 6.42.52
- Extract: streamingData.adaptiveFormats or streamingData.formats where mimeType contains "audio/mp4" or "audio/webm" (itag 140 = 128kbps AAC, itag 251 = 160kbps Opus).
- The returned direct URL (.googlevideo.com) is completely deciphered and plays immediately in HTML5 <audio>.

3. Automatic Fallback Pipeline:
- If ANDROID_MUSIC returns no stream, immediately retry with the IOS client:
  - clientName: "IOS", clientVersion: "19.09.4", X-YouTube-Client-Name: "5", User-Agent: "com.google.ios.youtube/19.09.4 (iPhone16,2; U; CPU OS 17_4 like Mac OS X)"
- If IP-gated on datacenter environments, resolve directly in the client's browser (client-side fetch) so requests originate from residential user IPs.

4. Related Songs & Continuous Radio Recommendations:
- POST to https://www.youtube.com/youtubei/v1/next with videoId.
- Recursively extract compactVideoRenderer items from secondaryResults to obtain matching continuous recommendations.
