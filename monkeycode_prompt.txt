6. SMART ZERO-DUPLICATE QUEUE & PLAYBACK LOGIC
1. Single-Song Search Playback:
 - Tapping a song from search results plays ONLY that track immediately and initiates smart related radio recommendations, without polluting the queue with 20 mismatched search items.
 - An explicit "Play All Search Results" button is provided for playing the full search list.
2. Track Action Menu on Every Row:
 - "Play Now": Starts track immediately.
 - "Play Next": Inserts track at index queueIndex + 1 directly after current song.
 - "Add to End of Queue": Appends track to the end of the queue.
 - "Like / Save": Toggles saved state in localStorage.
3. Smart Deduplication Engine:
 - When adding songs or loading recommendations, checks both track.id and normalized title (removing tags like [Official Video], (Lyrics), [HD]) so the same song or duplicate live version is never played twice.
4. Continuous Autoplay Radio:
 - When the queue has 2 or fewer songs remaining and Autoplay is enabled, queries Lavalink for related mixes based on the current track and adds 8 unique, unplayed tracks to the upcoming queue.
5. Queue Drawer Actions:
 - "Shuffle Upcoming": Shuffles future songs without interrupting the currently playing song.
 - "Clear Upcoming": Removes future songs while keeping the active song playing.
 - Move Up / Move Down buttons for manually ordering upcoming tracks.
